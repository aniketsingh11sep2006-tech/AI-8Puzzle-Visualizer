Algorithm Reference

Deep technical breakdown of every search algorithm with complexity analysis.

BFS

Breadth-First Search

Explores all nodes at the present depth before moving to nodes at the next depth level. Uses a queue (FIFO) as the frontier.

Complete?✓ Yes
Optimal?✓ Yes (unit cost)
TimeO(bd)
SpaceO(bd)
Best for finding the shortest path but uses a lot of memory.
DFS

Depth-First Search

Explores as far as possible along each branch before backtracking. Uses a stack (LIFO) as the frontier.

Complete?✗ No (infinite loops)
Optimal?✗ No
TimeO(bm)
SpaceO(b·m)
Very memory-efficient but may explore very deep paths unnecessarily.
DLS

Depth-Limited Search

DFS with a preset depth limit ℓ — nodes beyond this depth are not explored. Avoids infinite descent.

Complete?~ If ℓ ≥ d
Optimal?✗ No
TimeO(bℓ)
SpaceO(b·ℓ)
Useful when the solution depth is known approximately.
IDDLS

Iterative Deepening DLS

Runs DLS repeatedly with increasing depth limits (0, 1, 2, …) until the goal is found. Combines BFS completeness with DFS memory efficiency.

Complete?✓ Yes
Optimal?✓ Yes (unit cost)
TimeO(bd)
SpaceO(b·d)
The practical go-to for uninformed search — optimal and memory-efficient.
GBFS

Greedy Best-First Search

Expands the node that appears closest to the goal using only the heuristic h(n). Uses a priority queue ordered by h(n).

Complete?~ In finite spaces
Optimal?✗ No
TimeO(bm) worst
SpaceO(bm)
Very fast in practice but can be misled by inaccurate heuristics.
A*

A* Search

Expands the node with the lowest f(n) = g(n) + h(n), where g(n) is cost so far and h(n) is an admissible heuristic. Optimal and complete.

Complete?✓ Yes
Optimal?✓ Yes (admissible h)
TimeO(bd) best case
SpaceO(bd)
Gold standard for single-agent pathfinding — optimal with admissible heuristic.

Heuristic Functions

📐 Manhattan Distance

Sum of horizontal + vertical distances each tile must travel to reach its goal position.

h(n) = Σ |rowi − goal_rowi| + |coli − goal_coli|
Admissible & Consistent

🔢 Misplaced Tiles

Count of tiles that are not in their goal position (excluding the blank tile).

h(n) = |{i : tilei ≠ goali, tilei ≠ 0}|
Admissible (dominated by Manhattan)

About the Project

Project Overview

This interactive tool was built as an Artificial Intelligence course assignment to demonstrate and compare classical search algorithms on the 8-Puzzle problem — a benchmark AI problem that has been studied since the 1960s.

The 8-Puzzle consists of a 3×3 grid with tiles numbered 1–8 and one blank space. The objective is to rearrange tiles from an initial configuration to a goal state using the minimum number of moves.

The State Space

The 8-puzzle has 9! / 2 = 181,440 reachable states. Only half of all configurations are solvable — determined by the parity of the permutation.
